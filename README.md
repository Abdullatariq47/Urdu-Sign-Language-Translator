# Urdu Real-Time Sign Language Tranlator

This project aims to develop a real-time system that translates Urdu sign language gestures into text, facilitating communication for people who are deaf or hard of hearing. It leverages the power of yolov5, a state-of-the-art object detection model, for accurate sign language recognition.

## Key Features

- Real-time Translation: Processes live video input and translates signs into Urdu text in real-time.
- High Accuracy: Achieves an F1 score (recall) of 85% and confidence of 79%, ensuring reliable translation.
